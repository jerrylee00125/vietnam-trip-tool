## 🇻🇳 為什麼需要它？

走進越南店家，看到 `150.000 ₫`、`500k` 這類標價，常常會一時搞不清楚到底是多少新台幣。

「越南購物小幫手」是為台灣旅客設計的輕量工具，讓你逛街時可以快速換算越南盾、整理購物清單，付款前再確認一次應付金額和找零，不必站在櫃檯前努力數零。

## ✨ 它可以幫你做什麼？

- 💱 **快速換算越南盾**：依照實際換匯或刷卡情況，自行設定「1,000 越南盾約等於多少新台幣」。
- ⌨️ **看得懂不同標價**：支援 `150000`、`150k`、`1.2m`，也能正確把越南常見的 `150.000` 當成 150,000 越南盾。
- 🛍️ **邊逛邊記購物清單**：輸入商品名稱、單價與數量，自動加總越南盾和估算新台幣金額。
- 💾 **接續上次清單**：重新開啟後可以繼續計算，也能按下「開始新一筆購物」重新開始。
- 💵 **直接點鈔票付款**：看到手上的鈔票不用再輸入，點一下圖片就能加入付款金額。
- 🧾 **幫你算不足與找零**：立即顯示還差多少、付款是否剛好，以及應該找回多少錢。
- 📴 **沒有網路也能用**：第一次連網成功載入後，核心功能可以離線繼續使用。

## 🛒 四個步驟，買東西不再數零

1. **設定匯率**：在「快速換算」輸入目前使用的估算匯率。
2. **開始購物**：直接換算單一價格，或到「購物付款」加入商品、單價與數量。
3. **準備付款**：輸入要拿出的金額，也可以直接點選手上的鈔票圖片。
4. **核對結果**：看看金額還差多少、是否剛好，或店家應該找回多少，再確認實際鈔票。

## 📴 沒有網路時怎麼辦？

第一次開啟 APP 時需要連上網路，讓瀏覽器保存需要的頁面、程式與鈔票圖片。完成後，即使在收訊不穩的市場、店家或旅途中，仍可進行換算、建立購物清單與計算找零。

## 🔒 我的購物資料放在哪裡？

匯率與購物清單只保存在目前裝置的瀏覽器中：

- 資料不會上傳到伺服器。
- 不會在不同手機、電腦或瀏覽器之間同步。
- 清除瀏覽器的網站資料後，已保存的匯率、購物清單與離線檔案也會消失。
- 清除後只要重新連網開啟，即可再次建立離線快取。

## ⚠️ 出發前的小提醒

- APP 顯示的是依使用者設定匯率計算的**估算金額**，不是銀行、信用卡或換匯所提供的即時匯率。
- 鈔票組合與找零結果僅供旅途中快速核對，實際付款仍請確認商品價格、鈔票面額與店家找零。
- 不同換匯方式可能包含手續費或匯差，最終金額請以實際交易紀錄為準。
