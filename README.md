## 🇻🇳 為什麼需要它？

走進越南店家，看到 `150.000 ₫`、`500k` 這類標價，常常會一時搞不清楚到底是多少新台幣；到了櫃檯，手上又是一疊面額很大的鈔票，更容易越數越緊張。

「越南購物小幫手」是為台灣旅客設計的輕量工具。你可以快速雙向換算越南盾與新台幣、查看九種鈔票的台幣估值、整理購物清單，付款前再確認應付金額和找零，不必站在櫃檯前努力數零。

## ✨ 它可以幫你做什麼？

- 🔁 **雙向快速換算**：可切換「越南盾 → 台幣」或「台幣 → 越南盾」，切換時會自動帶入前一次換算結果。
- 💱 **自訂目前估算匯率**：依照換匯單、刷卡或實際取得的匯率，自行設定「1,000 越南盾約等於多少新台幣」。
- ⌨️ **看得懂不同標價**：支援 `150000`、`150k`、`1.2m`，也能正確把越南常見的 `150.000` 當成 150,000 越南盾。
- 💵 **九種鈔票換算參考**：直接查看 500k 到 1k 的鈔票圖片，以及依目前匯率估算的新台幣金額。
- 🛍️ **邊逛邊記購物清單**：輸入商品名稱、單價與數量，自動加總越南盾及新台幣估值。
- 🧭 **購物、付款分兩步驟**：商品算完後再按「前往付款」，手機畫面更集中，不用在長頁面中來回尋找。
- 💾 **接續上次清單**：重新開啟後可以繼續計算；首次進入購物頁時會以柔和發光提醒，也能按「開始新一筆購物」重新開始。
- 👆 **直接點鈔票付款**：依照手上的鈔票逐張點選，APP 會自動累加付款金額與張數。
- 🧾 **幫你算不足與找零**：立即顯示還差多少、付款是否剛好，以及應該找回多少錢和鈔票組合建議。
- 📴 **沒有網路也能用**：第一次連網成功載入後，核心功能可以離線繼續使用。

### 台幣換越南盾

可輸入 `1000`、`1,000` 或小數金額。換算結果會四捨五入到最接近的 1,000 越南盾，比較符合現場使用紙鈔付款的情況。

## 🧮 快速換算怎麼用？

1. 在快速換算頁選擇「越南盾 → 台幣」或「台幣 → 越南盾」。
2. 輸入金額，或點選下方的快捷金額。
3. 查看換算結果與計算方式；需要反向確認時，直接切換方向即可。
4. 在「目前估算匯率」調整自己的換匯基準，下方九種鈔票的台幣估值也會立即更新。

> 九種鈔票換算卡片是辨識與價格參考，不會加入付款金額；要實際計算付款，請前往「購物付款」的第二步驟點選鈔票。

## 🛒 購物付款怎麼用？

1. **建立購物清單**：輸入商品名稱、越南盾單價與數量，確認購物總額及可收合的鈔票建議。
2. **前往付款找零**：清單有商品後按「前往付款」，畫面會立即顯示本次應付金額。
3. **輸入或點選鈔票**：直接輸入付款金額，或依照手上的九種鈔票逐張點選。
4. **核對結果**：確認金額還差多少、是否剛好，或店家應找回多少及建議的鈔票組合。

返回購物清單時，商品、付款金額與已點選的鈔票張數都會保留；重新整理後則會從購物清單步驟開始。

## 📴 沒有網路時怎麼辦？

第一次開啟 APP 時需要連上網路，讓瀏覽器保存需要的頁面、程式與鈔票圖片。完成後，即使在收訊不穩的市場、店家或旅途中，仍可進行換算、建立購物清單與計算找零。

網站更新後需要再次連網開啟，讓瀏覽器取得新版內容；完成更新後，新版也能繼續離線使用。

## 🔒 我的購物資料放在哪裡？

匯率與購物清單只保存在目前裝置的瀏覽器中：

- 資料不會上傳到伺服器。
- 不會在不同手機、電腦或瀏覽器之間同步。
- 清除瀏覽器的網站資料後，已保存的匯率、購物清單與離線檔案也會消失。
- 清除後只要重新連網開啟，即可再次建立離線快取。

## ⚠️ 出發前的小提醒

- APP 顯示的是依使用者設定匯率計算的**估算金額**，不是銀行、信用卡或換匯所提供的即時匯率。
- 台幣換越南盾會取整到 1,000 越南盾；鈔票組合與找零結果也僅供旅途中快速核對。
- 實際付款時仍請確認商品價格、鈔票面額與店家找零。
- 不同換匯方式可能包含手續費或匯差，最終金額請以實際交易紀錄為準。
