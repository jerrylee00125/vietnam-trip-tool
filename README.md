# 越南購物小幫手

`vietnam-trip-tool`

給台灣旅客使用的越南盾換算與購物付款工具。面對 `150.000`、`500k` 這類看起來數字很大的越南盾價格時，可以快速估算新台幣金額、整理購物清單，並在付款前確認應付與找零。

## 立即使用

開啟 GitHub Pages：<https://jerrylee00125.github.io/vietnam-trip-tool/>

## 主要功能

- **越南盾快速換算**：依照自己實際換匯或刷卡的情況，設定「1,000 越南盾約等於多少新台幣」。
- **多種金額輸入方式**：支援 `150000`、`150k`、`1.2m` 與越南常見標價 `150.000`。
- **購物清單**：記錄商品名稱、單價及數量，自動加總越南盾與估算新台幣金額。
- **上次清單保存**：重新開啟後可接續上次清單，也能選擇「開始新一筆購物」立即重設。
- **付款鈔票選擇**：直接點選越南鈔票圖片，累加準備拿出的付款金額。
- **付款與找零**：顯示金額不足、付款剛好或應找回多少，並提供由大到小的鈔票組合建議。
- **離線使用**：首次連網成功載入後，核心功能可在沒有網路時繼續使用。

## 金額輸入範例

| 輸入內容 | 代表金額 |
| --- | ---: |
| `150000` | 150,000 越南盾 |
| `150k` | 150,000 越南盾 |
| `1.2m` | 1,200,000 越南盾 |
| `150.000` | 150,000 越南盾 |

## 使用方式

1. 在「快速換算」設定目前估算匯率。
2. 直接輸入越南盾金額換算，或到「購物付款」加入商品、單價與數量。
3. 輸入準備支付的金額，也可以直接點選下方的鈔票圖片。
4. 核對應付、還差或應找回的金額，並在櫃檯前再次確認實際鈔票。

## 離線使用與資料保存

第一次開啟時需要連上網路，讓瀏覽器保存 APP 所需的頁面、程式與鈔票圖片。完成後，即使暫時沒有網路，仍可進行換算、建立購物清單與計算找零。

匯率與購物清單只保存在目前裝置的瀏覽器中：

- 資料不會上傳到伺服器。
- 不會在不同手機、電腦或瀏覽器之間同步。
- 清除瀏覽器的網站資料後，已保存的匯率、購物清單與離線檔案也會消失。
- 清除後只要重新連網開啟，即可再次建立離線快取。

## 技術資訊

- 原生 HTML、CSS 與 JavaScript
- 響應式設計，支援手機與桌面瀏覽器
- PWA 與 Service Worker 離線快取
- LocalStorage 保存匯率與購物清單
- GitHub Pages 靜態網站部署
- 無後端、資料庫、外部 API 或第三方套件

## 使用提醒

- APP 顯示的是依使用者設定匯率計算的**估算金額**，不是銀行、信用卡或換匯所提供的即時匯率。
- 鈔票組合與找零結果僅供旅途中快速核對，實際付款仍請確認商品價格、鈔票面額與店家找零。
- 不同換匯方式可能包含手續費或匯差，最終金額請以實際交易紀錄為準。
