## 🇻🇳 為什麼需要它？

走進越南店家，看到 `150.000 ₫`、`500k` 這類標價，常常會一時搞不清楚到底是多少新台幣；到了櫃檯，手上又是一疊面額很大的鈔票，更容易越數越緊張。

「越南購物小幫手」是為台灣旅客設計的輕量工具。你可以快速雙向換算越南盾與新台幣、查看九種鈔票的台幣估值、整理購物清單，付款前再確認應付金額和找零，不必站在櫃檯前努力數零。

## ✨ 它可以幫你做什麼？

- 🔁 **雙向快速換算**：可切換「越南盾 → 台幣」或「台幣 → 越南盾」，切換時會自動帶入前一次換算結果。
- 👋 **第一次使用有引導**：可選擇直接輸入匯率、用換匯金額計算，或先使用清楚標示的預設估算值。
- 💱 **整合換算基準**：在同一張卡片直接修改匯率，或輸入付出的臺幣與拿到的越南盾，自動算出這次真正換到的匯率。
- ⌨️ **看得懂不同標價**：支援 `150000`、`150k`、`1.2m`，也能正確把越南常見的 `150.000` 當成 150,000 越南盾。
- 💵 **九種鈔票換算參考**：直接查看 500k 到 1k 的鈔票圖片，以及依目前匯率估算的新台幣金額。
- 🛍️ **邊逛邊記購物清單**：輸入商品名稱、單價與數量，自動加總越南盾及新台幣估值。
- 🧭 **購物、付款分兩步驟**：商品算完後再按「前往付款」，手機畫面更集中，不用在長頁面中來回尋找。
- 💾 **接續上次清單**：重新開啟後可以繼續計算；首次進入購物頁時會以柔和發光提醒，也能按「開始新一筆購物」重新開始。
- 👆 **直接點鈔票付款**：依照手上的鈔票逐張點選，APP 會自動累加付款金額與張數。
- 🧾 **幫你算不足與找零**：立即顯示還差多少、付款是否剛好，以及應該找回多少錢和鈔票組合建議。
- 💬 **越南常用語字卡**：依購物、餐飲、交通及溝通求助分類，按「查看」就能放大越南文直接出示。
- ⭐ **自訂常用字卡**：預設準備 8 張實用句子，也能自行加入、取消、清空或恢復預設內容。
- 📴 **沒有網路也能用**：第一次連網成功載入後，核心功能可以離線繼續使用。

## 🔢 金額怎麼輸入？

### 台幣換越南盾

可輸入 `1000`、`1,000` 或小數金額。換算結果會四捨五入到最接近的 1,000 越南盾，比較符合現場使用紙鈔付款的情況。

## 🧮 快速換算怎麼用？

1. 第一次使用時，先選擇「用換匯金額幫我算」、「我知道匯率，直接輸入」，或「先用預設值 NT$1.30」。
2. 在快速換算頁選擇「越南盾 → 台幣」或「台幣 → 越南盾」。
3. 輸入金額，或點選下方的快捷金額。
4. 查看換算結果與計算方式；需要反向確認時，直接切換方向即可。
5. 要調整時展開「換算基準」，下方九種鈔票的台幣估值也會立即更新。

> 預設值只供估算，不是銀行、信用卡或換匯所提供的即時匯率。設定完成後會保存在目前瀏覽器，下次開啟不會再次顯示首次引導。

### 實際換匯匯率怎麼算？

1. 展開「換算基準」，選擇「用換匯金額計算」。
2. 在「我實際付出」輸入臺幣，例如 `3,660`。
3. 在「我實際拿到」輸入越南盾，例如 `3,000,000`、`3m` 或 `3.000.000`。
4. APP 會依照「臺幣 ÷ 越南盾 × 1,000」計算；以上範例會得到「1,000 越南盾 = NT$1.22」。
5. 確認金額正確後，按「使用 NT$1.22」，所有快速換算、鈔票價格、購物清單與付款找零會一起更新。

輸入內容只保留在這次開啟期間；只有按下套用後的估算匯率會保存在目前瀏覽器。

> 九種鈔票換算卡片是辨識與價格參考，不會加入付款金額；要實際計算付款，請前往「購物付款」的第二步驟點選鈔票。

## 🛒 購物付款怎麼用？

1. **建立購物清單**：輸入商品名稱、越南盾單價與數量，確認購物總額及可收合的鈔票建議。
2. **前往付款找零**：清單有商品後按「前往付款」，畫面會立即顯示本次應付金額。
3. **輸入或點選鈔票**：直接輸入付款金額，或依照手上的九種鈔票逐張點選。
4. **核對結果**：確認金額還差多少、是否剛好，或店家應找回多少及建議的鈔票組合。

返回購物清單時，商品、付款金額與已點選的鈔票張數都會保留；重新整理後則會從購物清單步驟開始。

## 💬 常用語字卡怎麼用？

1. 前往底部的「常用語」分頁，第一次使用會先展開「常用字卡」。
2. 從購物付款、餐飲、交通或溝通求助分類找到需要的句子。
3. 按星號可加入或取消常用字卡；新加入的內容會依加入順序排列。
4. 按「查看」會開啟全畫面大字卡，將放大的越南文直接展示給對方看。
5. 「清空常用」及「恢復預設」都會先再次確認，避免誤觸。

常用語內容固定收錄在 APP 中，不使用即時翻譯服務，也不需要把輸入內容傳送到網路。上次展開的分類與自訂常用字卡會保存在目前瀏覽器。

## 📴 沒有網路時怎麼辦？

第一次開啟 APP 時需要連上網路，讓瀏覽器保存需要的頁面、程式與鈔票圖片。完成後，即使在收訊不穩的市場、店家或旅途中，仍可進行換算、建立購物清單、計算找零及查看常用語字卡。

網站更新後需要再次連網開啟，讓瀏覽器取得新版內容；完成更新後，新版也能繼續離線使用。

## 🔒 我的購物資料放在哪裡？

匯率、購物清單、常用字卡及上次展開的常用語分類只保存在目前裝置的瀏覽器中：

- 資料不會上傳到伺服器。
- 不會在不同手機、電腦或瀏覽器之間同步。
- 清除瀏覽器的網站資料後，已保存的匯率、購物清單與離線檔案也會消失。
- 清除後只要重新連網開啟，即可再次建立離線快取。
